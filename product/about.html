Built by Kyungsim (Chloe) Lee

ASNM은 초기 창업자의 가정 점검과 의사결정 학습을 위한 프로젝트입니다. 연구는 aSSIST MSTM 학위 연구에서 시작되었습니다. 현재 버전은 의사결정 지원 파일럿이며 상용 서비스 수준의 사업 효과는 아직 검증하지 않았습니다.

A decision-support project for early founders, developed from an aSSIST MSTM thesis. The current version is a product-experience pilot; commercial decision-quality benefits remain unvalidated.

Methodology & limits

n=190 SEM 연구는 인지편향 인식·지각된 유용성·도입 의도의 경로를 검토했습니다. 15명 사용성 파일럿은 SUS 82.2를 보고했습니다. 이는 생존 예측 정확도, 창업자 유형의 심리측정 타당성 또는 이번 v4 UX의 사용성을 검증한 값이 아닙니다.

The n=190 SEM study examined the adoption pathway; a 15-participant pilot reported SUS 82.2. Neither validates survival predictions, founder typology, or the new v4 user experience.

Version & roadmap

v4.0 — Decision World, same seeded financial model 1.0.0. Rule-based advice is available offline; LLM advice uses the optional server-side proxy and validated role responses. The main site uses GitHub Pages.

  1. Validate first-decision completion with novice founders.
  2. Replace scenario defaults with evidence from customer interviews and operating records.
  3. Test repeat use, decision learning and willingness to pay before adding billing or accounts.
  4. Calibrate model coefficients with observed outcome data; no current predictive accuracy claim.
