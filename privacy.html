브라우저 기록 / Browser records

디지털 트윈의 사업 가정, 결정, 이유, 회고는 이 브라우저의 localStorage에 보관됩니다. 데모와 개인 사업 세션은 별도 키로 저장됩니다. 계정·클라우드 세션 저장이나 기기 간 동기화는 없습니다. 브라우저 사이트 데이터 삭제로 지울 수 있으며, JSON 내보내기·가져오기로 옮길 수 있습니다.

Venture assumptions, decisions, reasons and reflections are stored in this browser’s localStorage. Demo and personal sessions use separate keys. There is no account, cloud session storage or automatic device sync. Delete browser site data to remove records; export/import JSON to transfer them.

AI 자문 / AI advice

새 Decision World에서 AI 자문은 선택적으로 활성화합니다. 활성화하면 현재 사업의 모델 상태와 전달한 문장을 설정된 서버 프록시를 통해 AI 제공자에 전송합니다. 이전 Module 1~3의 AI 검색·컨설턴트는 해당 요청을 실행할 때 입력 내용을 전송합니다. API 키는 브라우저에 저장하지 않습니다. 별도 운영자 설정을 확인하지 않아 서버 로그나 AI 제공자의 보관 정책을 확정할 수 없습니다.

AI advice in Decision World is optional. Enabling it sends the current model state and your message through the configured server proxy to the AI provider. Legacy Modules 1–3 send prompts when you run their AI search or consultant. API keys are never stored in the browser. Server logging and provider retention depend on operator configuration and are not confirmed here.

기능 측정·피드백 / Measurement & feedback

새 제품 이벤트는 세션 메모리의 기능별 카운터로 정의되어 있습니다. 이 버전에는 외부 분석 수집기가 없으며 사업 내용·재무 수치·식별자는 이벤트에 포함하지 않습니다. 피드백 응답은 내보내기 파일에만 저장하고 자동 전송하지 않습니다. 사용자가 GitHub에 직접 공유하면 해당 서비스의 공개 범위와 정책이 적용됩니다.

Product events are aggregate feature counts in session memory. This version has no external analytics collector and excludes venture content, finances and identifiers. Feedback is exported locally, not automatically submitted. Sharing it on GitHub is a separate user action subject to that service’s visibility and policies.

외부 서비스·음성 / External services & speech

호스팅은 GitHub Pages입니다. 기존 페이지는 외부 폰트·차트 리소스를 사용할 수 있습니다. 음성 입력은 브라우저의 음성 인식 구현을 사용하며 해당 브라우저 제공자가 음성을 처리할 수 있습니다. 마이크 권한은 사용자가 말하기를 누를 때 요청됩니다. 텍스트 입력으로 같은 흐름을 사용할 수 있습니다.

Hosting uses GitHub Pages. Legacy pages can load external fonts and charts. Speech input uses the browser’s recognition implementation, which may process audio through its provider. Microphone permission is requested when you choose Speak. Text supports the same workflow.
